# GymManager
Crea GymManager, un SaaS para gimnasios con dos áreas: Business (socios, pagos, clases, empleados y estadísticas) y Members (perfil, membresías, horarios y reservas). Usa React, TypeScript y Tailwind CSS. Diseño moderno, responsive y profesional en negro, blanco y azul eléctrico. Código organizado y escalable.
